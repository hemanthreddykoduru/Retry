# Recovery Call Skill

Use this skill when attempting a recovery call or checking contact eligibility.

## Guidelines:
1. Confirm the case and check contact eligibility before doing anything else.
2. Start only an approved recovery action. Never start a call if the status says it is ineligible (e.g., due to quiet hours or bank downtime).
3. Record the outcome of the action clearly.
4. **NEVER** claim money was recovered unless the system explicitly confirms it via the outcome recording or webhook data.
